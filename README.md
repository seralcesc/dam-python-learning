Repositorio de aprendizaje donde documento ejercicios, prácticas y pequeños proyectos desarrollados con **Python** durante mi formación en el Ciclo Formativo de Grado Superior de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

El objetivo del repositorio es mantener un registro organizado de los conceptos trabajados y reflejar mi evolución progresiva con el lenguaje.

---

## Objetivos

- Consolidar los fundamentos de Python.
- Aplicar los conceptos mediante ejercicios y prácticas.
- Mejorar progresivamente la organización y legibilidad del código.
- Documentar mi evolución durante el aprendizaje.
- Utilizar Git y GitHub como parte habitual del flujo de trabajo.

---

## Organización

Cada bloque agrupa ejercicios relacionados con un concepto concreto.

Cuando resulte útil, los ejercicios dispondrán de su propio directorio para facilitar su identificación.

### Ejemplo

```text
03-bucles/
│
├── 01-tabla-multiplicar/
│   └── main.py
│
├── 02-numeros-pares/
```
